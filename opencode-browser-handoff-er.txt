# opencode-browser-handoff-er.txt

Emergency / generalized handoff for the QUICKJS NETWORK BROWSER work.
Read this first on any fresh session. Goal: functional parity with the
chromium-based browser path — real pages render + are interactive through
the manager, zero JS errors, end-to-end — then keep going.

-------------------------------
## 1. THE TASK / ACCEPTANCE
-------------------------------
Drive real web pages (YouTube is the shakedown target) through the
quickjs-based network browser:
  `network_browser_manager.c` (manager / orchestrator, split into the
  ./.desktop +x manager; resident worker, curl, cookies)
  `ops/nb_js_worker.c` (the resident quickjs worker: DOM engine, page
  scripts, event loop, render-back) + `nb_dom.c` `nb_css.c` + vendored
  quickjs in `../js/`.

Acceptance line (paraphrased, ongoing): opening https://www.youtube.com/
must yield a static render with NO js errors, the home element tree wired
(bootstrap incl. `#search-icon-legacy` live), native search click/enter
drives a page NAV, results URL lands in page.state, cookies persist,
`make check` stays 60 PASS / 0 FAIL. Bugs are fixed as they surface until
that is true.

- Worker daemon protocol over a socketpair/stdin-pipe; frames are
  `XXXXX\n` length+`\n` content. Commands: `LOAD\n<body>` (fields
  page_js/fetch_dom/href/title/style.css), `EVAL\n<js>` (single line),
  `QUIT`. Worker replies `STATUS ok|err:...`, `LIVE|drain|%u`,
  `RENDER\n<rows>`, `WERR| script %d: ...`, `=>BOX_SET ...`,
  `=>NAV_REQUESTED` etc. In resident mode the worker stays alive for
  repeated EVALs; run_event_loop() keeps the drain going.
- Manager side: `#.desktop/network_browser_request.txt` one line per
  tick; `go:<url>` -> do_fetch (curl -> fetch.html/fetch.dom -> LOAD);
  `eval:<js>` / `go:eval:<js>` -> worker EVAL + merge_render_rows;
  NAV frames (`NAV\n<kind>\n<url>`) -> do_fetch again. Status file
  `network_browser_status.state.txt`; page.state rows `TITLE|`,
  `URL|`, `TEXT|`, `LINK|`, `BOX|`...
- Houses (the manager's working dir): `/tmp/nbhouseNN` — each holds
  `&.hq-apps/network/tmp/{page.js,page.js.ext*.js,fetch.dom,fetch.html,
  style.css,nb_curl_cookies}` + err/state files. Latest useful:
  nbhouse31u. IMPORTANT: crash/reboot wipes /tmp houses; artifacts are
  ephemeral. `nb_curl_cookies` persists cookies across navs.
- Quoted-path rule: house paths contain `&`, `#`, `!`, spaces — always
  quote; a bare `&` in the shell backgrounds the command.
