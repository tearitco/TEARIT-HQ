WRAITH LOOK ASCII J3
Plain text mockup of the intended shell shape

This is the ASCII-only version of the visual reference in
`!.look-of-wraith-gui.txt`.

It is intentionally coarse. The goal is to capture composition:
outer shell, left launcher list, floating overlapping windows, footer/taskbar.

Interpretation notes:
- The outer border is the desktop shell.
- The left side is the launcher/menu column.
- The framed boxes are floating peer windows, each with its own chrome.
- The `GAME MAP` window is intentionally offset so it overlaps the shell and
  protrudes past the shell border on the left.
- The main shell title is terminal-like, because this should feel like a real
  desktop shell rather than a docs page.
- The bottom strip is the taskbar/footer.
- The ASCII map is a placeholder for real content and should be replaced by
  actual project/content rendering once the shell composition is right.
