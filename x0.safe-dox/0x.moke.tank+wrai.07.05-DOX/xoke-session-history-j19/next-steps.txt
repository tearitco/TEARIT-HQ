Implementation rule
- Do not scrape the terminal output after the fact if it can be avoided.
- Build the summary at the point each action is dispatched in the manager.
- Append those concise entries into the existing `turn_summary` buffer.
- Write `turn_summary` into:
  - `projects/xo-pet-v1/pieces/manager/gui_state.txt`
  - `projects/xo-pet-v1/session/state.txt`

Why this is the right level
- The full debug trace already exists in manager logs and action prints.
- The visible frame should stay compact so the user can verify state changes quickly.
- This keeps the UI useful for humans and for future agents without turning the frame into a wall of text.
