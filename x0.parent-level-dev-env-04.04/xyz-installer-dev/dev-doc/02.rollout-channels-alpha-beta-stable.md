# 🚦 dev-doc — Rollout Channels: alpha / beta / stable

> Companion to `01.versioning-with-gitlet🌳🪵️.md`. Defines what each channel
> MEANS and the gate that must pass before promoting. Strategy status: **draft,
> for review.**

## 📡 The channels

| Channel | Branch (gitlet) | Who runs it | Bar to enter |
|---|---|---|---|
| 🌋 **alpha** | `alpha` | You + early testers + agents | Harness-green (KPI ladder) for the change itself |
| 🧪 **beta** | `beta` | Friendly users | Alpha soak: no new regressions, user-walkthru done |
| 🌳 **stable** | `master` | Everyone | Beta soak: no blockers, docs updated, version stamped |

Only **forward** promotion: alpha → beta → stable. Never skip a gate; never
push a channel backward.

## 🚧 The gates (one file each)

A release is a **descriptor set** (see gitlet doc): `catalog.pdl`,
`installed_apps.pdl`, `paths.pdl`, per-app `RELEASE.pdl`. A release is
*promotable* when ALL gates pass:

### 🌋 To enter alpha
- [ ] Change ships with a harness scenario → `proof/` dir is green
- [ ] No regression in the other KPI harnesses (re-run before cutting)
- [ ] `RELEASE.pdl` bumped with a new version (`0.x.0-alpha`)

### 🧪 To promote alpha → beta
- [ ] Alpha soaked: ≥1 real session (human or agent) with no new bugs
- [ ] User-walkthru doc updated for the new behavior
- [ ] Version re-stamped `x.y.0-beta`

### 🌳 To promote beta → stable
- [ ] Beta soaked: no known blockers
- [ ] Official docs (`xyz-official-documentation/`) updated — status tables match reality
- [ ] Version re-stamped `x.y.0` (stable; `x.y.z` for hotfixes)

## 📏 Version numbers

`MAJOR.MINOR.PATCH` in `RELEASE.pdl`:

- **MAJOR** — breaking layout/identity changes (e.g. `home/` → `home-🏠️`
  migration, Option A/C switch)
- **MINOR** — new capability (avatar flows, install op, versioning wiring)
- **PATCH** — fixes with zero behavior change to the contract

## 🧭 How a promote actually happens

Mechanically: re-point the channel ref at the newer tip, sync the descriptor
tree, publish (see gitlet doc §"Promotion ladder" + `promote.sh`, to be built).
The gates above decide *when*, the script decides *how*.

## 🎯 Why channels (the honest pitch)

- Installs get a **channel they opt into** (recorded in
  `installed_apps.pdl` / `paths.pdl`), not "whatever the dev pushed last".
- A **broken stable never ships by accident** — alpha/beta absorb the oops.
- **Agents can test** against alpha without touching a real user's stable
  install — same `$HOME`-isolation trick as the KPI harnesses.
