# 🧪 For Developers — Harness & Proof Discipline

> **Harness before hype.** If it isn't harness-green, it's a wish. ✨

## 🎯 The rule

A feature is "done" when a **real key-injection harness** goes green in a
`proof/` dir — and a **human** has walked the same path once. Not when a demo
video looks nice.

## 🔑 The primitives (tk ops)

Reusable, self-contained C ops that type into a live app session:

| Op | Usage | What it does |
|---|---|---|
| `tk_inject_key` | `<session_dir> <decimal_key_code>` | Appends one `KEY_PRESSED` line to `pieces/keyboard/history.txt` |
| `tk_type_text` | `<session_dir> <text>` | Types a string through the same channel |
| `tk_focus_item` | `<session_dir> <frame> <label>` | Focuses a UI item by label |
| `tk_assert_contains` | `<file> <substring> <label>` | Asserts a frame contains a string |

Key codes that matter: `13`=Enter, `27`=Escape, `127`=Backspace.

## 🎬 Scenario shape (copy this)

```bash
#!/bin/bash
# scenario - proves: <list of facts>
set -u
HARNESS_DIR="$(cd "$(dirname "$0")/.." && pwd)"
PROJECT_DIR="$(cd "$HARNESS_DIR/.." && pwd)"
OPS="$HARNESS_DIR/ops/+x"
PROOF_DIR="$PROJECT_DIR/proof/harness-$(date +%Y%m%d-%H%M%S)"
mkdir -p "$PROOF_DIR"
FAIL=0
pass() { echo "PASS: $1"; }
fail() { echo "FAIL: $1"; FAIL=1; }
cleanup() { ...reap processes...; }
trap cleanup EXIT          # ← ALWAYS cleanup, even on crash
key()  { "$OPS/tk_inject_key.+x" "$1" "$2"; sleep 0.2; }
check() { "$OPS/tk_assert_contains.+x" "$1" "$2" "$3" >/dev/null; [ $? -ne 0 ] && FAIL=1; }
...
# 1. boot the app  2. wait for frame  3. inject  4. assert  5. save proof frames
```

## ✅ House rules

- ⏱️ Run under a **timeout**; kill everything via `trap cleanup EXIT`.
- 🧹 No stragglers — reap by binary name, verify via `/proc/<pid>/exe`.
- 🖼️ Save **proof frames** at each stage (`00_initial`, `01_after_*`, …).
- 🧯 Use **full-frame grep**, not tail-N — tall UI footers push results out.
- 🏁 Exit nonzero on any FAIL. Green = every `PASS:` line ran.
