# 👤️ For Users — Install & First Login

> Everything here has been **harness-proven** — a clean machine, real
> keystrokes, zero humans in the loop. You are the human now. 🎉

## 📦 1. Install xyzos

You need the installer package (`xyz-installer-dev/`). It reads its dev-tree
source from `pointers.pdl`; you usually pass nothing.

```bash
# from the folder that contains xyz-installer-dev/ :
bash xyz-installer-dev/xyzos-starter-install.sh
```

What it does, in order:

1. 🔨 **Copies** `00.login-signup` + `01.avatar-creation👤️` into
   `~/xyzos/apps/` (names preserved — renaming login breaks avatar's link).
2. ⚙️ **Compiles** both apps in place (`button.sh compile`).
3. 🌱 **Creates a fresh `xyzfs/`** — guest `session.pdl`, zero users.
4. 🏪 **Seeds the app-store**: `catalog.pdl` + `installed_apps.pdl`.
5. 🧭 **Writes `paths.pdl`** — the pointer file (logical name → real path).
6. 🚀 **Writes the launcher** `~/xyzos/button.sh`.

**Guarantees:**

- 🔒 **Non-destructive** — refuses to run if `~/xyzos/` already exists.
- 🔗 **One-way copy** — the dev tree is read, never written.
- 💾 **Self-contained** — the installed tree works without the dev tree.

## 🚀 2. Boot & sign up

```bash
~/xyzos/button.sh
```

You'll see the login screen (`U S E R - P A L`). Type a **User ID** and a
**Display Name**, hit **Create Account**. You're in: a UUID is minted for you,
and your very own filesystem branch appears.

## 🔄 3. Log out / in

- **Log Out** → back to "Not logged in."
- **Log In** → type your User ID, hit **Log In**. Same identity comes back —
  same uuid, same files. This is the whole point. 🎯

## 🧪 4. Quick self-check (did it work?)

| Ask | Look for |
|---|---|
| Did my home-🏠️ get created? | `ls ~/xyzos/xyzfs/users/<uuid>/` → `home/` exists |
| Am I logged in? | The screen says `Logged in as: <you>` |
| Where's my account? | `~/xyzos/apps/00.login-signup/users/<your-id>/profile.txt` |

## 🆘 5. Troubleshooting

| Symptom | Fix |
|---|---|
| Installer refuses | `~/xyzos/` already exists → move/rename it or use a different `$HOME` |
| Login screen missing | Re-run `bash xyzos-installer-dev/xyzos-starter-install.sh` (compile step) |
| Something feels stale | Files are the truth: read `~/xyzos/paths.pdl` before hunting |
