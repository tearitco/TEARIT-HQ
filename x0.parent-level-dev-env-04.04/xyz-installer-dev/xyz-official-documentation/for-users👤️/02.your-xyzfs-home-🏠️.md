# 🏠️ For Users — Your xyzfs Home

**xyzfs** is the xyzos filesystem: every signed-up human gets their own branch,
keyed by a durable **uuid**, not a name. Names change; uuids don't. 🪪

## 🌳 The layout (Option B — APPROVED)

```
~/xyzos/
└── apps/00.login-signup/xyzfs/        ← the multi-user filesystem root
    ├── session.pdl                    ← who's logged in (or guest) on this machine
    └── users/
        └── <uuid>/                    ← ONE branch per human (the durable id)
            ├── meta.txt               ← machine facts about this user
            └── home-🏠️/               ← this user's home (physical dir: "home")
                ├── avatars/<uuid>/    ← created by the avatar app
                ├── wallet.txt
                ├── projects/  net/  exchange/
```

## 🏷️ Home naming (the confusing part, solved)

Two different "homes" exist on your machine:

| Name | What | Example |
|---|---|---|
| `home-🏠️/` | **Your xyzfs home** — inside the OS | `~/xyzos/xyzfs/users/<uuid>/home/` |
| `$HOME` | **Your Linux home** — where the OS itself lives | `/home/you/` |

Rule of thumb: 🏠️ emoji = xyzos. `$` = Linux. Always labelled, never confused. 🎯

## 🪪 Identity chain (follow the truth)

1. **Signup** mints a uuid from `/proc/sys/kernel/random/uuid`.
2. Your **login name** is the account *key*: `users/<name>/profile.txt`
   (duplicate names are refused).
3. Your **data branch** is the uuid: `xyzfs/users/<uuid>/`.
4. `current_login.txt` + `session.pdl` say *who* is logged in *right now*.
5. The **pointer** `~/xyzos/paths.pdl` says *where everything is* (logical
   name → real path) — the single place layout facts live.

## 🗄️ What's durable vs throwaway

| File | Durability | Why |
|---|---|---|
| `users/<name>/`, `xyzfs/users/<uuid>/`, `current_login.txt`, `session.pdl` | ✅ **Durable** | Your identity must survive any session |
| `pieces/sessions/<id>/` | ♻️ **Throwaway** | Per-run UI state, recreated on boot |
| `app-store/*.pdl` | ✅ **Durable** | What's installed, this user's ledger |

## ⚠️ The one rule that saves you

> **If it's real, it's in a file.** Never trust what a screen "showed you".
> When in doubt: `grep` the file. 📁
