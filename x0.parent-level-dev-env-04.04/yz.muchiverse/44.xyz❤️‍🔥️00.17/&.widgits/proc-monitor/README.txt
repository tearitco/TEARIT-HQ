proc-monitor widget — PLAN
==========================
GL-primary process list for house programs (headless or windowed).

User can:
  - see running processes (from xyzfs runtime registry + live PID check)
  - FOCUS one (for file-menu / other widgets)
  - KILL / soft-quit
  - maybe open/raise GL window later
