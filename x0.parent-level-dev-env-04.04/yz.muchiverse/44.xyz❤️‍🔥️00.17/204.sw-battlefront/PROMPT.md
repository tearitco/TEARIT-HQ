# PROMPT — Star Wars Battlefront house clone

Build a self-contained freeglut C game with:

1. **Supremacy** — command posts, tickets, team AI
2. **Deathmatch** — frag limit, space arena, kill buffs
3. **Freeplay** — multi-planet survival/building, ships, blasters, lightsabers

Quality bar: shaders, generative textures, instancing, fluent flight, rich HUD.
POSIX `button.sh`, ~60fps timer (no glutIdleFunc).
