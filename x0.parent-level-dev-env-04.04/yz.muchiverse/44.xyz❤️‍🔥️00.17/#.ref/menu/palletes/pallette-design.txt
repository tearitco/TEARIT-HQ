VIEW SPECS (direct instruction, 2026-08-24, "the palette view should be
a matrix. and there should be a scroll thumb"; emojis: "just use the
colored one for now")
---------------------------------------------------------------------------------
MATRIX VIEW    Every category window shows its tiles as a GRID (matrix),
               not a vertical list. Composition-side: tiles are chunked
               into <row class="pal-grid-row"> containers of N tiles -
               khtpm_render_core.c's css_layout_pass() genuinely recurses
               into nested flex containers, so row-of-tiles children of
               the panel's column stack lay out horizontally with no new
               engine code. Tile cell size comes from .pal-tile CSS
               (width/height), not the panel's default 22px row height.
SCROLL THUMB   Grid content taller than the window scrolls, and there is
               a REAL VISIBLE THUMB on a track at the panel's right edge
               (proportional thumb size/position from scroll_offset).
               House guidance for the mechanics, verified live:
               - wraith-alpha fs browser: g_scroll_offset + fixed
                 visible-window size + clamp [0, max_scroll] where
                 max = total - visible (wraith-alpha ops' fs pattern,
                 cited by open-hai's file header).
               - chat / open-hai transcript: same offset+clamp plus
                 nav-badge-numbered "Scroll Up"/"Scroll Down" rows
                 (step 3) and a "line X-Y / Z" position readout
                 (khtpm_open_hai_render.c ~1318-1340, 1649-1655) - that
                 is chat's "up down nav thumb".
               Palettes combines both: real drawn track+thumb AND
               mouse wheel (Button4/5) AND PageUp/PageDown keys; nav
               indices are only assigned to VISIBLE cells so digit-jump
               never targets scrolled-out tiles; focus-follow adjusts
               the offset when arrow/digit nav moves focus out of view;
               offset resets to 0 whenever the chtpm reloads.
EMOJI SOURCE   The emojis category reads #.ref/menu/palletes/
               emoji-pallet-00.00.txt (112 colored emojis, one per
               line) - NOT any hand-picked monochrome starter set.
