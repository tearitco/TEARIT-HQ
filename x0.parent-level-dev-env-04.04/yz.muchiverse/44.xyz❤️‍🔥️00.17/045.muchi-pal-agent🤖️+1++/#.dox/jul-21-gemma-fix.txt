     the state.txt ai_state="THINKING" -> "IDLE" transition and/or the

Both point at the SAME kind of problem the earlier "random-words"
misdiagnosis in api-fix.txt was chasing before it turned out to be a
red herring: a poll-loop / state-transition ordering issue in THIS
project's own pipeline code (send_message.c -> connect_op.c ->
check_response.c -> main_loop_chtpm.pal's render gate), not anything
external.

THE ACTUAL DIFFERENCE - diff the three `button.sh run` actions:
