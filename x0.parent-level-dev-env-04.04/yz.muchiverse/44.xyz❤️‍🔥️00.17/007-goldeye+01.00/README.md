# 007-goldeye — voxel GoldenEye split-screen

**No mouse.** Open island terrain, 4 biomes, mountains, water, trees, tanks, helis.

## Run
```sh
sh button.sh compile
sh button.sh run
sh button.sh kill
```

## Play controls
| Key | Action |
|-----|--------|
| **↑ / ↓** | Forward / Back |
| **← / →** | Strafe |
| **A / D** | Turn left / right |
| **J** | Jump |
| **PgUp / PgDn** | Look up / down |
| **F** | Fire |
| **E** | Enter / exit tank or heli |
| **Space** | Sprint |
| **Esc** | Menu |
| **P** | Pause (debug/cheats placeholder) |
| **1** | First-person camera |
| **2** | Third-person camera |
| **S** | Reset camera |
| **Ctrl+C** | Quit |

Menu: arrows select, Left/Right change players (2-4), Enter starts. Frag limit 10.
