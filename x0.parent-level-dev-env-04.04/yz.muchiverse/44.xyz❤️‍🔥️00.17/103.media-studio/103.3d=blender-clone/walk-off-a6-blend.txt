## What works now
- Blender-shaped UI: File, tools, 3D viewport, outliner, status
- Orbit (MMB), pan (Shift+MMB), zoom (wheel)
- Objects: cube / sphere / ground primitives
- G/R/S grab-rotate-scale with X/Y/Z constrain, confirm/cancel
- Select via click / outliner / number keys
- Wireframe Z, frame selected `.`
- **Import .obj / .fbx** (Assimp) + house-path drag-drop (`media_drop_path`, kind=4 mesh)
- Title-bar ✕ quit (WM_DELETE not eaten by XDND)
- CPU-safe fps cap + main-loop sleep

## Depends
- `libassimp-dev` (`pkg-config assimp`)
- freeglut + GL/GLU/X11

## Not yet
- Edit mode, modifiers, UV, materials, lights as objects, animation, OBJ export
- Full mesh raycast pick / multi-select
- CHTPM shell / canvas-widgit FBO path
