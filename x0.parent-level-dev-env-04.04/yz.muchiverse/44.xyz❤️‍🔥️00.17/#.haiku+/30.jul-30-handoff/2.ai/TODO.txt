TODO 4 (FIXED 2026-07-31): gemma "TOOL: ..." hallucination after typing
"dir list" + tool result rendered above the user message
=======================================================================
SYMPTOM (user report): typing "dir list" produced a frame where Aida
"answered" with `TOOL: read file jul-21.txt` instead of a clean listing.

ROOT CAUSE, PART 1: build_gemma_request() (ops/send_message.c) replayed
old persisted `assistant|tool_call` turns to gemma3:270m as literal
"assistant: TOOL: X {args}" text. The model imitated that format in its
reply. Live-caught: llm_response.json contained exactly
`"TOOL: read file jul-21.txt"`.

ROOT CAUSE, PART 2 (cosmetic): strategy_execute_a ran BEFORE send_message
appends the user's own message, so its tool|result append rendered ABOVE
the "You: ..." line that triggered it.

FIX (per explicit user decisions, all harness-proven):
  - build_gemma_request() now SKIPS assistant|tool_call turns at
    prompt-build time only (before comma placement, no dangling "{}," in
    the JSON). Persisted context_log template untouched (user chose
    filter-not-purge). tool|* result turns still fed as TOOL_RESULT.
  - New state.txt toggle model_after_tool=no (default): when strategy A
    just pre-ran a tool, send_message flushes the result then returns
    IDLE WITHOUT calling any LLM ("Tool result shown."). Set
    model_after_tool=yes to re-enable model commentary after tool runs.
  - Display order fixed via tool_result.pending handshake:
    strategy_execute_a stashes (tool name + raw result), send_message
    flushes it into context_log right after the user turn, deletes the
    file. tool_result_pending= is the handshake field.
  - Old check_response.c PENDING_PERM → execute_tool.c/deny_tool.c flow
    and text_to_pal_prompt.c's llamacpp replay: LEFT AS-IS (user chose).

VERIFIED: demo_list_dir_tool.sh OVERALL PASS with two NEW assertions
(KPI#2: no `TOOL: (read|write|list|run|search|speak)` in last 12 frame
lines; KPI#3: result line number > user message line number). Proof:
045.muchi-pal-agent🤖️+1/proof/harness-20260731-113214/. Full narrative +
plan in #.haiku+/30.jul-30-handoff/2&3-jul31-sprint.md §6b.
