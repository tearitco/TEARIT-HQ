## 🔑 The one idea that threads all three topics

**File-mediated relay is the ONE mechanism this whole house uses for
everything** — process A writes a file (or a tray directory of files),
process B polls/watches and reacts, neither side calls the other
directly. You've already seen this pattern up close if you did the
editor/file-menu work this session:
`interact_relay.txt` (buttonless-layout key injection),
`pieces/keyboard/history.txt` (buttoned-layout key injection),
`pieces/apps/*/widget_cmds/inbox+status` (cmd-bus between widgets),
`current_frame.txt`→`rgb_frame.raw`→GL window (the render pipeline
itself). Topic 1's "drag a GL window into another" is this same
mechanism with a **tray directory** (`#.desktop/inbox|events|tiles/`)
instead of one file, because a tray needs to hold multiple named,
discoverable items. Topic 3's app-install and multi-agent isolation are
this same mechanism again, scoped **per-user** instead of per-project.
Once you see this, all three topics stop looking like three unrelated
asks and start looking like the same pattern applied at three different
scopes (widget↔widget, app↔desktop-tray, user↔user).

## 🧪 The standard this whole house now holds itself to

Every recommendation across all three companion docs assumes
`!.xyzos-standards+1.txt` §36.6 (renamed this session from
`!.pal-standards+1.txt` — see that file's own header note for why
"xyzos" is now the more accurate name than "pal" for the whole
ecosystem this doc governs, not just the prisc+x VM specifically): real
key injection through real running processes, asserting the rendered
frame AND the real files on disk, never an op-level shortcut treated as
proof a feature works. `!.xyzos-pitfalls+1.txt` PITFALL 58 (the
`fm_enqueue_cmd` wrong-cwd bug that a passing op-level harness never
caught) is the concrete, real incident behind that rule — it is cited
directly in companion docs 1️⃣ and 3️⃣ because the exact same failure
shape is waiting in every NEW widget/app/agent this handoff proposes
building, if the same discipline isn't applied from day one.
