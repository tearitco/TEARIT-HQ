## 🏎️ Fastest path to get acclimated (direct guidance, not deferred)

1. Read `EVENTS_RUNTIME.md`'s own "Quick status check" — confirms EXACTLY what already works
   (as of last check: a single `page_1`/`on-click`/numeric-state-change event, nothing more).
2. Don't assume multi-page, other triggers, or dialogue events work — they weren't built as of
   that doc's writing. Verify against `EVENTS-PAL-BUILDOUT-PLAN.md` for what's since landed.
3. For "teach the AI" specifically: start SMALL — one single, already-working event type
   (Change Gold) as the reference example, not the whole vocabulary at once.
