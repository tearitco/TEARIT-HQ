**⚠️ Real, standing architectural risk, confirmed live 2026-08-18**: `khtpm_open_hai_manager.c` and
`khtpm_open_hai_render.c` each keep their OWN SEPARATE copy of the model list (`g_models[]`) — this
is BY DESIGN per the house's shell/manager split, not an oversight, but it means **any model-list
change must be made in BOTH files by hand** or the render side silently falls back to its own
default. Confirmed by finding exactly this drift live this session. Flag this explicitly in any
prompt that touches model selection.

different concern) unless the task specifically involves h-ai controlling taskbar state files.
