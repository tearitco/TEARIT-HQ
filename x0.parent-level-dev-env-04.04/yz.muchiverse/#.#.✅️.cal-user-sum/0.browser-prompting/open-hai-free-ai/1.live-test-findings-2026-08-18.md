## ⚠️ Real, concrete gotcha found live

Asking the model to read a path containing special characters (`&.widgits/open-hai/README.md`)
produced a WRONG path in its tool call — the `&` got dropped (`.widgits/open-hai/README.md`).
Root cause not yet isolated to a specific layer (model-side JSON re-emission is the most likely
culprit given `list_dir path="."` worked fine with no special characters) — **flag this, don't
assume it's fixed**: give free-tier models SIMPLE, unambiguous paths, or better, resolve the path
yourself and hand it a value with no punctuation-heavy directory names when precision matters.

## 📝 Best prompts to give it (real, tested shape)

```
SEND|Use your read_file tool to read the file at path <FULL, UNAMBIGUOUS PATH RELATIVE TO
HOUSE ROOT>, then <specific, bounded ask - e.g. "summarize in one sentence">.
```

- **Always give a full path relative to house root**, not "the current directory" or a bare
  filename — tool paths resolve relative to house root, not to open-hai's own directory or
  whatever project you're discussing.
- **Keep asks narrow and single-purpose per message** — this matches the house-wide testing
  discipline already established (`TESTING_STRATEGY.md`'s own relay-only, one-action-at-a-time
  rule) and avoids the free-tier model losing track mid-multi-step-task.
- **For anything requiring `write_file`/`edit_file`/`run`**, expect to manually APPROVE each
  action — plan for a human in the loop, don't script an unattended multi-edit pipeline yet
  without also scripting the APPROVE side.

**Yes, open-hai + free-tier OpenRouter is usable for nontrivial prompting right now** — real

anything beyond read-only exploration.
