|----------|--------------|------------------|

### 1.3 Agent-native superpower 🤖

Because **state is files**, an agent (or intern) can:

1. 📖 Read `current_frame.txt` / receipts instead of guessing pixels  
2. ✍️ Inject keys into `history.txt` for harnesses  
3. 🧪 Diff checksums on `rgb_frame.raw` after a change  
4. 🔁 Port a fix once (e.g. Win `rename` freeze, MAP3D black map) across apps  

This is **R&D velocity as a product feature**, not a private CI trick.
