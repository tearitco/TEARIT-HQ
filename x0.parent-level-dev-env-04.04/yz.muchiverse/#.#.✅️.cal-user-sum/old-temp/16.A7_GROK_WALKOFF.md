## 2. Proven bug patterns (do not re-diagnose from zero)

### Win rename freeze (GL stale)
`write_file_atomic`: write `.tmp` → `rename` onto existing `rgb_frame.raw` **fails on Windows**.  
Symptom: GL never updates after first frame.  
Fix: `remove(path); rename(tmp, path);` else direct `fopen wb` (wsr already had this; muta rgb_render ported).

### MAP3D black map
`current_frame` has `0x01` marker + stale `rgb_frame_3d_overlay.receipt.txt` without real raw → rgb_render skipped map text rows.  
Fix: only skip rows if `blit_overlay()` returns success.

### win_spawn / Control Hero dead
`CreateProcessA` + bare `system/prisc+x` + absolute emoji path → `pid=-1`.  
Fix: wsr `CreateProcessW` + relative path + `.exe`.

### Terrain legend ASCII / Selected: ?
`fopen` on absolute host under emoji house fails; board path used `host_fopen` but legend did not.  
Fix: all host-side reads through `host_fopen` in board-viewer compose.

### Enter not seeding world (aomorai)
Not Enter missing: `.+x` spawn failed + ANSI fopen.  
Fix: `win_run_pe` + relative roots.
