**RAHWEH:** So — inference. How does a weight on a word actually turn into a predicted next word?

**MAXINE:** Real mechanics, briefly: each word's embedding gets projected through `W_q`/`W_k`/`W_v` into a query, a key, and a value. The query and keys score how much each earlier word should influence the current prediction — that's the "attention" — and the weighted sum of values, run through the rest of the network (`forward_prop.c`, `mlp_layer.c`), produces the next-token prediction. The per-word `weight` field feeds into that scoring from the very first layer, so a smarter starting weight genuinely changes what the model pays attention to, from training step one.

**THE NARRATOR:** Now — augmenting it. FSM, RL, GOAP, LSTM. Where does each one actually help THIS real system?

**TOMO:** LSTM first, since it's the one genuinely NOT in this project yet — this is pure attention, no recurrent memory layer. An LSTM's real strength is cheap, sequential short-term memory; attention's strength is looking anywhere in context at once. They're not rivals, they're complementary — a future version of this project could add a small LSTM layer specifically for cheap turn-to-turn conversational memory, while attention keeps handling within-message word relationships. Real, buildable, not required for today's loot to be useful.

**MAXINE:** GOAP fits the ROUTING layer, not the language layer. Which curriculum should answer THIS message — that's a real small decision with real candidates (each loaded curriculum), exactly `corp_decide.c`'s own real decision_mode shape again. Score each curriculum's relevance, let a weighted or Gemma-assisted chooser pick, same pattern as NIGHT 8, applied to curriculum routing instead of stock trades.

**RAHWEH:** RL?

**TOMO:** Offline, same as always — train the ROUTING policy against many real conversation logs, reward correct-curriculum selections, and that trained policy becomes the MoE's real gate function over time, replacing a hand-coded routing rule the same way NIGHT 8's policy decision_mode replaced a live model call.

**THE NARRATOR:** FSM?

**MAXINE:** The conversation's own TURN STRUCTURE — is the bot listening, generating, waiting on a curriculum load, waiting on a human — that's a real, small FSM wrapped around the whole pipeline, the same cursword-proven shape from NIGHT 7. The neural net does the language; the FSM makes sure the SYSTEM around it never gets stuck in an undefined state.
