browser-prompting/ai-agents/5.local-gemma-harness-fallback-delegation.md

🐢🛠️ Local Gemma 270m/1b + Harness — the real fallback if OpenRouter hits quota

Real question this answers: if nvidia/nemotron-3.5-lightning:free/cohere/north-mini-code:free (see open-hai-free-ai/) hit their OpenRouter quota or a shared-pool 429, can a genuinely LOCAL, free, always-available model (gemma3:270m or gemma3:1b, already pulled on the LAN Ollama host) be pushed to a "reasonable level" via a harness — and specifically, can browser-AI prompting be used to build/extend that harness?

Direct answer, not guessed: YES, already measured, 9/9 PASS. Not via native tool-calling (that's flaky and hallucinates on small models — measured, not assumed) — via the Harnecient hack specifically: never tell the API we want tools, ask for short plain text, dispatch deterministically in the harness itself.

📊 The real, already-measured facts (cite these, don't re-test them)

Source: &.widgits/open-hai/code-tools-harness/api-test-results.md, dated 2026-08-12, real C harness (run_native_tools.c), real per-turn JSON receipts under results/<model>/.

ModelNative tool_callsHarnecient hack (read/edit/run)

The pattern: small/non-tooled models can't reliably decide WHEN to call a tool or format a call correctly — but they CAN reliably produce short, plain-text answers when a harness has already deterministically decided what tool to run and hands them a clean result to interpret. The harness does the routing; the model does the talking. Same idea DAY_15's own "DESCRIBE, not CLASSIFY" lesson teaches.

🐌 Real, user-reported (not yet independently measured): 7B is too slow right now

Direct report, 2026-08-18: llama3-groq-tool-use:8b (or a similarly-sized model on this LAN host) is too slow for practical interactive use at the moment. Not contradicted by anything on disk — api-test-results.md doesn't measure latency, only correctness — so treat this as real, current, unverified-by-a-formal-benchmark information: 270m/1b are the realistic local fallback tier right now, not 7B+.
