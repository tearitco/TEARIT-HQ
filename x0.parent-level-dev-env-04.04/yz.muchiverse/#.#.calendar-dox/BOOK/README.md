# TEARIT-HQ Book

The house's documentation, organized as a book: index, chapters,
glossary, examples, and a living appendix of daily progress. This is
the ONE place house-level (not per-app) documentation lives. Per-app
design docs stay next to their own app under `44.xyz.01.00/`.

Built 2026-09-02 by condensing ~120 scattered files from
`x0.parent-level-dev-env-04.04/yz.muchiverse/` root, `#.dox/`,
`#.#.calendar-dox/` (loose files + `1.^V-hq/`, `old-temp/`,
`resume-temp/`, `0.browser-prompting/`, `1-1.HARNECIENT.SMOL/`,
`2.SEPT/`), and the 17 loose `.md` files at `44.xyz.01.00/`'s root.
See each chapter's own `00-INDEX.md` for exact provenance of its
content.
