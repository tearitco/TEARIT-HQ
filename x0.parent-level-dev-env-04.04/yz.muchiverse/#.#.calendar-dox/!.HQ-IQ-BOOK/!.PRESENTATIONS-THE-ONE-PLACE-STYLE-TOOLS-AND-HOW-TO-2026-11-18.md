## 3b. Language rule: one voice, the OTHER language as subtitles, never both (SAID 2026-11-18)
The company has English and Japanese customers. A deck is made as a pair: **English voice with Japanese subtitles** (`-en-voice-ja-subs`) and **Japanese voice with English subtitles** (`-ja-voice-en-subs`). Never a voice and subtitles in the SAME language (redundant). The manifest caption is the subtitle text, so a deck needs two manifests (one per subtitle language) and one narration script per voice language; keep the two text sets side by side so they stay the same slides.
PITFALL (2026-11-18, RAN): the caption font is DejaVuSans, which has NO Chinese or Japanese glyphs: a CJK caption renders as empty boxes (seen in the first Teario deck). Japanese subtitles need a CJK font (Noto Sans CJK or WenQuanYi, both searched by the engine glyph code in `bv_cjk_glyph.c`) added as a fallback in the maker before any ja-subs deck.
NOT built or verified: `make_presentation_video.py` has no language option yet, and a Japanese Kokoro voice (needs the Japanese text front end for `kokoro-onnx`) has not been tried here; check it with a recorded level test before promising a Japanese deck. Today the caption strip shows the caption and the narration reads the same caption, which is exactly the redundant case to avoid.

## 5. A deck must show the real thing (house rules)
- Every slide is a real photograph of the running window with the state value next to it (`board_ctl snap` style receipts), not a mock-up. A slide with no picture is a lie by omission.
- Say what is proven and what is not on the last slide (label RAN / DOC).
- Never loop `ffmpeg`/`awk` over pixels (use a C op); heavy renders go through `cpu_gate` and `nice -n 15`.
