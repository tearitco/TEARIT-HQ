## What 100% means

A shipped screen samples no RPG Maker PNG. Every cell a player can see has a file under `out/good/` named by `roles.pdl`. Bad drafts, the flat catalog, the grass diffusion draft, and the color-code proof stay under `out/bad/` or `XO/31.Nov/nov-5/1.generator-sheets/0.bad/`. They are not mixed into good.

Equal or greater, for one cell, is all of these:

1. The outline is at least as specific as the RPG Maker cell it replaces. A flat fill fails. A boulder is a boulder, a tree is a tree.
2. Ground and wall that repeat use the house table in `tile_autotile.c`. Floor is 48 shapes. Wall is 16. Waterfall is 4. Each shape is four quadrants. A quadrant pixel equals the source block at that table coordinate. The harness fails otherwise.
3. The same cell, placed on a real map with neighbors, meets its neighbors in the 2D view. A screenshot of that map is the tiling check. The palette grid is not the check.
4. The 3D view of that same map uses the painted floor, so the seams are the same seams.
5. A person has kept it. The model may label it. The model does not draw it.

Greater is allowed: more shades, a Tear-it mark, a palette the owner names. It is not a license to drop a shape the old cell had.

## Character generator, 2026-11-05

Owner: a character generator, naked first, clothes added, like the original.

The original is a stack of parts, not one drawing. `generator_char_op` reads `LAYER` rows in order. `naked` paints the body. `shirt` paints one garment over the torso. `none` leaves that part off. Any other value is a 48×48 `sprite.csv` painted on top, which is how hair, a face, or a real garment comes in later. The editor page is `events/gen_character/event.pal`. The default list is body on, clothing off, hair off. The proportion is super-deformed, the RPG Maker one: the head is about half the figure, the torso and legs are short, and the marks are pixel blocks. `CONCEPT | color` and `CONCEPT | detail` name rows in `words.pdl`. The weight is that row. Colour maps to `guidance_scale` and detail (`w_crisp`) maps to `num_inference_steps`, the two arguments `img_draft.py` passes into `StableDiffusionPipeline`. The formula is `sd_map.h`: a bank weight of 0.50 is the script default, guidance 7.5 and 20 steps. `img_prompt` prints `GUIDANCE` and `STEPS`, and the draft script reads them. For `w_grey` 0.50 and `w_crisp` 0.70 the character run prints guidance 7.50 and 24 steps. Harness: `VERDICT|PASS|passed=12|failed=0`. No draft was run. It is a mannequin. It is not Asa or Ava. Views, both in bad: `XO/31.Nov/nov-5/1.generator-sheets/0.bad/0.char-naked.png` and `0.char-shirt.png`.

## Hand guide, so the swap comes sooner

Owner, 2026-11-05: a person guides. The generator does the heavy lifting.

The person does four things, and only those. Name the role (Asa, not an Actor1 frame). Name the layers that are on. Name the two word-bank rows, colour and detail. Say yes or no to the picture that comes back.

The generator does the rest, with the ops that already exist. `generator_char_op` stacks the layers into one 48×48 super-deformed cell and writes it under `out/bad/`. `sd_map.h` turns the two word weights into `guidance_scale` and `num_inference_steps`. `img_prompt` prints those lines. `img_draft.py` passes them into `StableDiffusionPipeline` when a draft is actually asked for. `generator_tile_op shapes` builds the 48 floor shapes from `tile_autotile.c` once a real block is the source. A rerun of the same file matches byte for byte. A changed layer or a changed weight is the only thing that moves a pixel or a step count.

A hand session is one loop. Edit one `LAYER` row or one `WORD` weight. Run the event page. Look at the png in `0.bad/`. Keep it by moving that file to `out/good/` and naming it in `roles.pdl`, or leave it in bad. The next session starts from the kept file, not from a new program.

## How this broadens

A new garment, a hair piece, or a face is another `LAYER` row whose value is a 48×48 `sprite.csv`. It is not a new op. A new look-word is another `WORD` row in `words.pdl`, kind `colour` or `style`, weight 0..1, and a person promotes it. A third concept maps onto an argument `img_draft.py` already passes (`--seed`, `--size`, `--px`), by one more line in `sd_map.h`, then both `img_prompt` and `generator_char_op` print it. The floor, the wall, and the object cell stay on `generator_tile_op`. The body stays on `generator_char_op`. Broadening is a row. A second painter is a second authority and is the thing this page refuses.

The walk of 3 frames by 4 directions is the same cell run twelve times, with a layer that is the frame. Faces and side-view are the same stack at their own size. Parallax is the same idea with a wide cell. None of those are built. The row shape is the one above. `events/gen_sprite_rtp/roles.pdl` now names Asa, Ava, Lucky, and Astra, with an empty picture. The lore page that was not read before that mistake is `22.lore-ip/SOUL-PEN-LORE-SUMMARY-2026-11-05.md` section 4: Asa preserves, Ava wants meaning, they are the last two ageless humans in the Eden archive, and Lucky = Asa = Sol is one identity line.
