## 5. Traps I hit (so you do not)
Non-ASCII and newline path names (TSOTS SECRETS has a newline in its name; the lore folders hold emoji): use `find -name` and `find -print0`, copy to scratch with safe names. A search of a **scratch copy** is not a search of the source: I wrongly said "no Venus source" after searching only my compiled-book copy; search the raw folders. A literal `|` in a harness `RUN`/`EXPECT` row splits the row (use `\p` or `printf '\174'`); `EXPECT_HAS` reads only 16 KB; an unknown harness verb is silently ignored; `head` in a pipe can kill the compiler (write logs to a file). Never run `python3 -` (it waits on stdin, and Python is not allowed). `pkill -f <pattern>` inside a tool shell kills that shell: kill by exact pid. The README of `13.agent-coms` and the working tree carry other agents' uncommitted hunks: stage by path, check `git diff --cached --name-only`. Never touch hotbar/window positions or the live theme without recording and restoring them.
