# 🗺️ !.HQ-IQ-BOOK-MAP — the whole book, compacted, chapter by chapter

Companion to `!.HQ-IQ-COMPACT🧭v0.1.md`. The **compact** file teaches you
the house in one read. **This** file is the *index to everything else*:
every chapter of `!.HQ-IQ-BOOK/`, every file in it, compressed to the
one line that tells you whether to open it. 📚➡️🗜️

Written 2026-09-09. Emoji-sectioned so you can eyeball-jump. When a
chapter has its own `00-INDEX.md`, that is still the authority for that
chapter — this is the *cross-chapter* skim.

**Reading order for a cold start:** `00-compact` → the chapter you need
below → that file. Resuming after a break: `09-appendix` handoffs first.
