WHAT "MIDDLE HOUSE" MEANS HERE
  The generation of apps between the first TPMOS terminal games and LyfeDesk (the khtpm / x11-hq window shell). Shape:
    button.sh run  ->  (orchestrator)  ->  system/keyboard_input  (owns the tty, writes keys)
                                           system/prisc+x         (runs pal/main_loop*.pal)
                                           system/renderer        (terminal frame, pieces/display/current_frame.txt)
                                           system/chtpm_parser_pal / chtpm_rgb_render (chtpm layouts -> rgb_frame.raw)
                                           system/gl_mirror       (OPTIONAL GL window that blits rgb_frame.raw)
  Target shape: ONE khtpm_core_render.+x window on an .xhtpm/.chtpm projection, a manager process, nothing else
  (see CENTROID_GOLD_STD.md). x11-hq = that window family. The terminal + GL pair goes away when the window is proven.

HOW THE LIST WAS MADE (so it can be redone)
  find ... -name button.sh (depth <= 4, not under pieces/sessions) whose folder has system/keyboard_input[.c] or
  system/gl_mirror[.c]; then read each button.sh for orchestrator / gl_mirror / renderer / khtpm_core_render /
  board-viewer run-widget. 35 launchers found; 30 are middle house (sections A and B), 5 are already x11-hq (section C).

DATES - READ THIS BEFORE TRUSTING A DATE
  * The git history starts 2026-08-25 and every project's first commit is the path migration of 2026-09-01, so git
    gives NO creation date for any of these.
  * 2026-10-05 is the working-tree restore day (INCIDENT-2026-10-05-WORKING-TREE-WIPE): every file restored then has
    that mtime. "earliest file" below is the oldest surviving file mtime; "10-05" means the real birth is NOT known.
    For those, the header comment's "modeled directly on <app>" lineage is given instead.
  * LyfeDesk anchors: khtpm renderer already in the first commit (2026-08-25); the word "livedesk" is in commit
    messages from 2026-08-29; the khtpm architecture standard is dated 2026-09-01; the taskbar tree itself shows 10-05
    (restored); renamed LyfeDesk on 2026-10-15. So: earliest < 08-25 = older than any evidence of the khtpm shell
    ("pre-LyfeDesk"); 08-25..09-01 = same era; later = built beside it (still middle house by shape).
