Engine rebuilt (`bv_menu_input` only); a session runs its own copy, so the editor must be relaunched to take it.
3. **Daemon consumer** (skin section 68, the main loop): reads new rows of the session's `place_requests.txt` (rows present at its first look are history), places each. It first sat in section 48, inside `follow_pchq()`, which returns early when the world's `map_id` is not `rpg-edit-hq` (the editor showed `book:rpg-space`), so it never ran: moved.
