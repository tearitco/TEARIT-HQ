### 3. Product Strategy — Sequence for Leverage
Priority order that maximizes learning and defensibility:

1. Ship the smallest real `ai_describe` round-trip on a terumon.
2. Stand up the test-bot harness so you generate high-volume, structured feedback without waiting for humans.
3. Turn the chatbot entity into the first public-facing “robot you can talk to” that actually has an inspectable bank. This is both product demo and data flywheel.
4. Only after the above is stable: surface the template/delta machinery so one good insight can propagate (with the multi-copy convergence rule protecting the shared template).
5. Networking work in parallel as infrastructure, not as feature work.

This sequence keeps the “everything is an event” claim honest. You never have to pretend a local multi-process test is real multiplayer.
