## Pitfalls that bit this session

- Windows cannot create dirs named `*.monads`. Alias at resolve; do not rewrite Linux PDL to `_.monads`.
- `New-Item -Path` glob-expands `*`. Always `-LiteralPath`.
- PowerShell 5 `Set-Content -Encoding utf8` writes a **BOM**. PDL: UTF-8 no BOM.
- Never `Get-Process | … $_.Path` (hangs). Kill by name.
- `system("taskkill…")` flashes a console per call. Use Toolhelp.
- Console-subsystem `.exe` flashes on spawn. Compile livedesk bins `-mwindows`; `CREATE_NO_WINDOW` on CreateProcess.
- `$.crypts` inside a PowerShell `-File` string expands as `$crypts`. Desktop starter launches `crypt_autostart.exe` directly.
- Agent/job launch can kill children unless `CREATE_BREAKAWAY_FROM_JOB`.
- Linux `strip_y_offset=50` is GNOME, not a Win inset.
