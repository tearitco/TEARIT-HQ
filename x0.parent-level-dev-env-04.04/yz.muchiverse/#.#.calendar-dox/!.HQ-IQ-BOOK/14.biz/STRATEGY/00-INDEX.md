# STRATEGY — company-wide

The default answer for each area. An OUTLET only gets its own
`pricing.md` / `networking.md` / etc. when its answer actually diverges
from what's here.

All files are `DRAFT` stubs — founder-owned. Agents may draft options
and structure; the founder decides. Nothing here is a commitment.

| File | Scope |
|---|---|
| `sales.md` | who buys, the buyer's "why now", pipeline, call structure, when lore helps vs. hurts a call |
| `marketing.md` | positioning, channels, the A/B demographic tests across outlets, content cadence |
| `pricing.md` | model options (free / paid tiers / services / game sales), not set |
| `networking.md` | target people/orgs/communities, warm-intro paths, event plan |
| `legal.md` | entity shape, IP/trademark, licensing (FOSS vs. proprietary split), privacy, contracts — needs real counsel |
| `ethics.md` | data use, AI use, marketing-lore boundaries, audience-targeting lines the founder will/won't cross |
| `strategy.md` | 6–18 month priorities, sequencing outlets vs. platform vs. games, kill/keep criteria |
