layout_runtime_keys.txt - names the board template uses that are NOT in any state file at rest, with who writes them. Used as one more --ui file by layout_check (one name, an equals sign, then its writer, per line; a line without an equals sign is a comment).
Invoke: layout_check pchq-board.xhtpm --ui ../state/ui.txt --ui ../state/clock_ui.txt --ui state/ui.txt --ui state/sides.txt --ui state/pal.txt --ui state/prefs_ui.txt --ui layout_runtime_keys.txt
Rule: a name belongs here only if a named writer exists in code and it is conditional or slot-based. A name nobody writes is a bug in the template, not a line here.
