# civ-rpgce

Clone of dsr-rpg (2026-10-14). Settlers Red, Blue, and Green are one viking armor cell, tinted. The ground is the OHR grass, town, house, castle, and forest sheets. Fog, huts, and founding a city are not built. Design: `#.#.calendar-dox/!.HQ-IQ-BOOK/16.game/CIV-RPGCE-DESIGN.md`.

Launch the board with `sh @.apps/civ-rpgce-board/button.sh run`. Room ids are still the dsr island so the doors keep working.


See also: this skin is NOT the civ game. The SNES-style Civ is the new app `@.apps/civ-snes` (decision D157, BOOK 16.game/CIV-SNES-2D-AND-3D-PLAN-2026-11-27.md).
