# 🏦 YAHOO-XYZ — BANK GUI + BROKER WIDGET 🏦

> **PURPOSE:** A brokerage terminal with a main **bank-balance GUI** window and a
> separate **broker GL widget**. Built on the same CHTPM/ledger architecture as
> `@.apps/text-editor-xyz/`, with the broker running as a reusable widget in its
> own GL window (same pattern as editor + file-menu).
>
> **Read `@.apps/my-chara-txt/MY_CHARA_TXT_DESIGN.md` first** for the base
> CHTPM/`piece.pdl`/ledger architecture, and `&.widgits/board-viewer/` for the
> proven widget-launcher pattern.

---

## 📖 1. THE VISION

A **bank + brokerage** terminal where you:

- 🏦 **Bank** — view balance, watchlist, last lookup (main GUI window)
- 📈 **Broker** — full brokerage in a SEPARATE GL window (portfolio, options,
  predictions, buy/sell stocks, deposit/withdraw)
- 🏪 **Multi-broker** — choose from a list of brokers, each with its own account,
  populated as dynamic `${piece_methods}` rows
- 💸 **Deposit / Withdraw** — transfer funds between bank balance and brokerage
  account

**Two windows, one app:**

| Window | Screen | Shows | GL? |
|---|---|---|---|
| **Main** | `bank.chtpm` | Balance + watchlist + [Open Broker Widget] button | Optional ASCII mirror |
| **Main** | `broker_select.chtpm` | List of brokers as `${piece_methods}` | Optional ASCII mirror |
| **Widget** | `broker_widget.chtpm` | Portfolio, options, predictions, trade, deposit/withdraw | **Own GL window** (required) |

## 🎮 4. THE INTERFACE — BANK + BROKER WIDGET

### Screens (main app)

| Screen file | Shows | Reached from |
|---|---|---|
| `bank.chtpm` | Balance, watchlist, last lookup, [Open Broker Widget] button | (entry point) |
| `broker_select.chtpm` | List of brokers from `brokers.txt` as `${piece_methods}` rows | `bank.chtpm` → [Select Broker] |
| `broker_widget.chtpm` | **Full broker UI** — portfolio, options, predictions, trade, banking | Spawned as widget from `bank.chtpm` |

### Broker Widget Screens (inside the widget's own `broker_widget.chtpm`)

| Screen section | Shows |
|---|---|
| **Portfolio** | Stocks, shares, current value, total equity |
| **Options** | Held options, pricing, buy/sell options |
| **Trade** | Buy/sell stocks by symbol + shares |
| **Predict** | Stock price prediction |
| **Banking** | Deposit / withdraw between bank and broker |

### Broker Selection (dynamic methods)

`broker_select.chtpm` uses `${piece_methods}` generated from a `piece.pdl`
regenerated by `yahoo_compose_frame` reading `brokers.txt`. Each row is a
numbered METHOD like:

```
METHOD | Fidelity (stocks+options) | SELECT_BROKER:FIDELITY
METHOD | Robinhood (stocks+options+crypto) | SELECT_BROKER:ROBINHOOD
METHOD | InteractiveBrokers (full-service) | SELECT_BROKER:IB
```

Selecting a broker spawns the broker widget with that broker's ID in its state.

## ⚙️ 5. OPS

| Op | Purpose |
|---|---|
| `yahoo_menu_input` | **The** METHOD-table dispatcher for bank + broker_select screens |
| `yahoo_compose_frame` | Per-screen renderer + dynamic `piece.pdl` regen for watchlist + broker list |
| `broker_menu_input` | METHOD-table dispatcher for broker widget screens |
| `broker_compose_frame` | Per-screen renderer for broker widget (portfolio, options, trade, predict, banking) |
| `deposit_withdraw` | Transfer funds between bank balance and broker account |
| `lookup_stock` | Fetch current price from Yahoo Finance API, cache to `yfin_master_list.txt` |
| `portfolio_new` | Calculate total portfolio value (stocks + options + cash) |
| `profit_loss` | Show profit/loss summary |
| `buy_stock` / `sell_stock` | Trade stocks |
| `buy_option` / `sell_option` | Trade options |
| `options_pricing` | Black-Scholes option pricing |
| `predictions` | Price prediction |
| `add_credit` | Add credit to bank balance |
| `read_price` | Read cached price |
| `fetch_stock` | Raw HTTP fetch from Yahoo Finance API |
| `json_parser` | Parse JSON responses |
| `ledger_append` | Append to `data/master_ledger.txt` |

**Reuse strategy:** All stock/option/portfolio ops are **ported directly** from
`YAHOO_XYZ/$.yahoo.fin+]h13]BRNFRZ/*.c` into this app's `ops/`. The orchestrator
loop (`1.yfin💴️._orch]h13.c`) is **replaced** by the CHTPM/PAL architecture —
no more `while(1)` menu loop, the PAL module + `piece.pdl` handles navigation.

## 🚀 7. BUILD ORDER

| Phase | What we build | Verified by |
|---|---|---|
| **P1** | Skeleton: `bank.chtpm` + `broker_select.chtpm`, basic balance display, broker list as dynamic methods | Real `button.sh run`: bank screen shows balance + watchlist, broker list renders correctly |
| **P2** | Broker widget: `&.widgits/yahoo-broker/`, spawn from bank screen, portfolio view in separate GL window | `[Open Broker Widget]` opens real GL window showing portfolio |
| **P3** | Deposit/withdraw: transfer between bank and broker, both screens update on change | Deposit $500 in widget → bank balance decreases, broker balance increases |
| **P4** | Trade: buy/sell stocks via broker widget, portfolio updates | Buy 10 NVDA → portfolio shows new position |
| **P5** | Options: options pricing, buy/sell options, portfolio includes options value | Buy 2 AAPL calls → options section shows position |
| **P6** | Predictions + profit/loss screens in broker widget | Predict NVDA → shows projected price |
| **P7** | GL/RGB mirror for main bank window (optional, gated on `NO_GL`/`DISPLAY`) | Bank window shows real rendered content in GL |

## 🤔 9. OPEN QUESTIONS / NOT YET DECIDED

1. **Broker widget reuse:** Should `&.widgits/yahoo-broker/` be tightly coupled to
   yahoo-app, or should it be generic enough for other finance apps? (Current
   direction: domain-specific but self-contained.)
2. **Multiple positions per broker:** Should `broker_acc` track individual stock
   positions per broker, or just a single balance? (Current direction: full
   portfolio per broker, same `usr_acc.<hash>.txt` format for positions.)
3. **Real-time updates:** Should the broker widget poll for price updates, or
   only refresh on user action? (Current direction: refresh on screen switch +
   explicit [Refresh] button.)
4. **Crypto support:** Should brokers that support crypto show crypto prices, or
   is that deferred? (Current direction: deferred — stocks + options only for P1.)

## 🏁 10. TL;DR

- Main bank GUI (`bank.chtpm`) shows balance + watchlist + button to open broker

  portfolio, options, predictions, trade, and deposit/withdraw
