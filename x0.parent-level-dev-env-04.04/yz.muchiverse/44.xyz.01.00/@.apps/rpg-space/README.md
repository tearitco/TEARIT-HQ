# rpg-space (R0 - R3, 2026-10-23)

A planned pets-like board that simulates a planet from a seed, solar system down to molecules. Design (paper): BOOK `16.game/RPG-DUST-DESIGN.md`. **There is no board, daemon or window yet.** What exists:

| File | What | Proof |
|---|---|---|
| `scale.pdl` | the scale ladder (10 levels), the universe `SEED` and the tweakable `PARAM` rows | `ops/+x/dust_check.+x ladder scale.pdl` -> `ladder ok: 10 levels, root system, seed 20261023, 5 params` (a PARAM may name its level; an unknown level is refused) |
| `reactions.pdl` | four hand-authored reactions (water, methane, photosynthesis, rusting) with public enthalpies | `ops/+x/dust_check.+x react ../../&.widgits/concept-bank/data/chem/elements.pdl reactions.pdl` -> `reactions=4 balanced=4 bad=0` |
| `ops/dust_gen.c` | **R2, the first real generator**: `region <scale.pdl> <addr> <out>` (16 x 16 smooth heights 0..99: 5 x 5 noise lattice, integer bilinear, small per-cell noise), `area <scale.pdl> <region-page> <cx> <cy> <addr> <out>` (zoom into one region cell), `page <scale.pdl> <addr> <out>` (the page at an address from the address alone; an address ending `/cell:cx,cy` is an area page), `zoom_in <addr> <cx> <cy>` / `zoom_out <addr>` (inverse address operations; an area address cannot be zoomed into, a region address cannot be zoomed out of; malformed cells exit 2), `export <page> <outdir>` (the board files for a page: `map.txt` band glyphs a..g, `ascii_legend.txt`, `terrain_legend.txt`, `extrusion.pdl`; band edges 20 / 35 / 45 / 65 / 80 / 92), `conserve <region-page> <cx> <cy> <area-page>` (the zoom invents and loses nothing: area heights sum to exactly 256 x the cell height, each 0..99; OK / MISMATCH). Integer arithmetic only, files byte-identical across runs | harness `dust_gen` 87 checks; all 256 cells of a real region also conserved by hand |
| `board/open_board.sh` + `board/pchq-board.xhtpm` | **R3, the first visible slice**: `sh board/open_board.sh [region addr]` exports the ledger's current address (region page and the zoomed area page) with `dust_gen export` into a pc-hq book `maps/rpg-space` (desks `region` and `area`) of its own instance `rpg-space-pchq`, installs the band legend as the instance `terrain_legend.txt`, and opens the shared pc-hq board with this folder's template copy. The template copy matters: the board projector writes `state/ui.txt` into the template's own folder, so with the default template it wrote into piececraft-hq's state and found no session ("loading..." forever) | RAN 2026-10-23: window "rpg-space board" shows the engine frame of the region (HUD `rpg-space:region`, minimap = the exported 16 x 16 page, voxel island in water / sand / grass / forest colours). Images: `XO/29.marathon-sprint-drive/rpg-space-board-window.png`, `rpg-space-engine-frame.png` |
| `ops/dust_zoom.c` + `verbs.pdl` + `events/{start,zoom_in,zoom_out}/` | **R2c, zoom as EVENTS**: verbs `start <region addr>`, `zoom_in <cx> <cy>`, `zoom_out`, `where`. The only state is the append-only `state/zoom_ledger.txt` (`START` / `ZOOM` / `REFUSED` rows); the current address is replayed from it; a refused zoom is recorded and changes nothing. The three pages were made by `verbgen gen` (`verbgen check` PASS) and are played by events-hq `play_event.sh` through the prisc VM, arguments in `PET_ARG` | harness `dust_zoom` 79 checks, including the real pages played in a scratch house |
| `ops/dust_addr.c` | text-include (two consumers): the address grammar (`split_cell`, N = 16) | used by `dust_gen`, `dust_zoom` |
| `ops/dust_hash.c` | text-include (two consumers): splitmix64 mix, child, fold, level_seed | used by `dust_seed` and `dust_gen` |
| `ops/dust_pdl.c` | text-include (two consumers, no state): pipe-row splitting and safe-copy helpers shared by both ops | built into both |
| `ops/dust_check.c` | the two checks (pure: read, print, exit code) | harness cases below |
| `ops/dust_seed.c` | R1: `mix` (splitmix64), `child <seed> <key>`, `path <seed> a/b/c`, `page <seed> <path> [n]` (n x n heights 0..99 from value noise on the page seed). Pure: same (seed, address) = same bytes, no clock / pid / rand | `mix 0` = e220a8397b1dcdaf, the published splitmix64 value; `lseed <scale.pdl> <level>` / `lpage`: the seed of a LEVEL, with each PARAM folded in at its level (4th field, default root; sorted by name, so row order is irrelevant): a parameter moves its level and everything below, never a level above. Harness `dust_seed` 79 checks |
| `../../&.widgits/_shared-lib/chem_formula.c` | per-element atom counts from a formula (text-include; same grammar as `chem_label.c`, which is untouched) | used by `dust_check` |

Build: `sh ops/build_dust_check.sh` builds both ops (`-Wall -Wextra -Werror`).
Harness (pal + locked cases, `&.widgits/_shared-lib/harness/`): `dust_ladder.pal` 64 checks, `dust_react.pal` 39 checks, `dust_seed.pal` 79 checks, `dust_gen.pal` 115 checks, `dust_zoom.pal` 79 checks. Run with a many-args prisc VM (harness README). Negative tests are part of the cases; two deliberate code mutants (react detects only lost atoms; ladder allows an equal-size child) were each caught by the harness on 2026-10-23.

Prior art to read before building more: `&.widgits/physics-nodes/`, `&.widgits/solar-sandbox/`, `SOLAR-SANDBOX-AND-PLANET-PHYSICS-DESIGN.md`, `REAL-3D-PLANET-EXPLORATION-AND-REALTIME-MODE-DESIGN.md` (design section 2b lists them).
NOTE for anyone playing the pages by hand: `MUCHI_TARGET_ENT` must point INSIDE the house (the page walks up to `xyzfs` to find the op); the pets games use `<app>/state/world`. Outside the house the page runs, exits 0 and does nothing.
Board caveats (seen on 2026-10-23): the 3D camera starts low at the hero, so only part of the island is in frame and the hotbar popup of the board covers the lower middle; the `0` key through the relay did not switch to a top-down view; the `area` desk was not looked at; the zoom pages are NOT wired to buttons or menu rows of this window (they are run with `play_event.sh`); `sh board/open_board.sh` leaves the board running (close it from the taskbar). The first launches showed "loading..." until the template copy was used; two earlier launches left no engine session at all after a teardown, cause not found.
Not built: the zoom pages are not wired to any window or button, other generators (area is the last level made; no system / globe / body / molecule generator), a viewer or board (the pages are text files nobody can look at yet), anything below cell 16 x 16 per page, rivers / biomes / coasts (heights only; ocean_fraction is in the seed but does not shape terrain yet), zoom, the overrides ledger, anatomy, the board skin, the address grammar.
