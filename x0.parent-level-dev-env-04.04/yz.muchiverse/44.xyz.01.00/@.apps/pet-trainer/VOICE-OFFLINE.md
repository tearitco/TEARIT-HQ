# Pet voice: offline (Kokoro) instead of edge-tts (2026-10-14)

**Why:** Microsoft's read-aloud service has refused the edge-tts websocket with HTTP 403 since 2026-10-12 (probe on 2026-10-14 still 403), and many pets speaking at once could hit a rate limit anyway.
**What:** `ops/pet_tts_local.py` is a drop-in for the old `edge-tts` command: `--voice <name> --rate=+10% --pitch=+30Hz --text "..." --write-media <file>`. It maps the voice name through the `KMAP | edge voice | kokoro voice | language` rows in `voices.pdl`, uses the rate as speed, ignores pitch, and writes a WAV to the given path (the callers re-encode it with ffmpeg, which reads the format from the content, not the name).
**Who calls it:** `ops/pet_voice.sh` (pet-trainer, shell) and the `speak()` function in the six C apps `rpg-pet`, `cdda-hq`, `gta-hq`, `df-hq`, `dsr-rpg`, `mcl-hq` (path `<app>/../pet-trainer/ops/pet_tts_local.py`). One authority for the voice mapping: **pet-trainer/voices.pdl**. The other apps' own `voices.pdl` files keep their VOICE rows (they are the keys) but no KMAP rows are needed there.
**Limits (known):** no pitch control; no Korean voice in Kokoro (voice name `ko-KR-InJoonNeural` maps to `-`: the pet is silent); a new phrase takes 4-9 s of CPU (2 threads, nice 10, one synthesis at a time via `~/.cache/pet_tts/synth.lock`), then it is cached as wav per pet and phrase; text is cut at 240 characters; the six voices that sounded different through pitch now differ only by voice and speed.
**Model files:** `~/.local/share/kokoro/kokoro-v1.0.int8.onnx` and `voices-v1.0.bin` (same files as `#.#.calendar-dox/1-1.HARNECIENT.SMOL/convert_night_to_audio_local.py`).
**Verified 2026-10-14:** the script made audio for en-US, en-GB, ja and zh voices (peak 0.44-0.72, 0.9-2.7 s each); `pet_voice.sh 2 "..."` produced and played a wav in a scratch state dir; the exact argument form the C code uses produced a file ffmpeg converted; all six C apps rebuild. **Not verified:** a live pet speaking in a running window (windows must be relaunched to load the new binary), the Korean pet, many pets at once.
**Go back to edge:** if edge-tts works again, revert the one-line path change in each C file (`git revert` of the commit that added this file) and the `pet_voice.sh` line; nothing else changed.
**Offload note:** this runs on the dev machine because it is tiny and cached; if many new phrases are needed at once, run them on debil/Mac (owner's rule).
