## Config File (Runtime-Editable)

**Location**: `#.desktop/vm_rv_li/config.pdl`

**Format**: Each line is `key | value` (pipe-delimited, house §7 live-edit pattern).

**Current Values** (2026-10-05):
```
emu_root | /home/debil/Desktop/github/RVLV_EMUL
emu_bin  | build/main
emu_args | --virtio-legacy -k images/xv6-kernel.bin -f images/xv6-fs.img
cols     | 80
rows     | 24
```

**Path Resolution** (per manager code):
- `emu_root` is absolute (full path to emulator repo)
- `emu_bin` is relative to `emu_root` (so full path = `emu_root/emu_bin`)
- `emu_args` paths are **relative to emu_root** (working directory of spawned emulator)
  - E.g., `images/xv6-kernel.bin` → `/home/debil/Desktop/github/RVLV_EMUL/images/xv6-kernel.bin`
  - E.g., `kernel/Image` → `/home/debil/Desktop/github/RVLV_EMUL/kernel/Image`

**To change OS at runtime**:
1. Edit `#.desktop/vm_rv_li/config.pdl` (live, no rebuild)
2. Manager re-reads config each tick
3. Next emulator spawn uses new `emu_args`
