The main toolbar in RPG Maker (such as in MV/MZ) provides quick-access buttons for project management, map editing modes, and testing tools. The core toolbar options include New Project, Open, Save, Cut, Copy, Paste, Delete, Select Mode (Map/Event), Layers, Database, Plugin Manager, Character Generator, and Playtest.Project & File OptionsNew Project: Starts a fresh game directory.Open: Loads an existing project file.Save: Saves current progress.Editing & Selection ToolsCut / Copy / Paste / Delete: Standard clipboard actions for tiles and events.Map Design Mode: Switches focus to drawing map tiles.Map Events Mode: Switches focus to placing and editing interactive events.Layer Select (1, 2, 3, A): Controls which map layer you are actively drawing on.Shadow Pen: Adds automatic shadow effects to map structures.Tools & GeneratorsDatabase: Opens actors, items, skills, and system rules.Plugin Manager: Adds and configures JavaScript plugins.Resource Manager: Imports or deletes game assets (audio, graphics).Character Generator: Builds custom character sprite sheets and faces.PlaytestPlaytest: Launches the current game to test your changes.
