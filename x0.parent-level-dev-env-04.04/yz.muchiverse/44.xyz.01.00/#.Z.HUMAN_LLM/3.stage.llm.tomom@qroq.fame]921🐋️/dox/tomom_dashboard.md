# Tomom Hand-Tuning Dashboard (Phase K)

## Architecture

The dashboard provides an explainable AI interface for monitoring and hand-tuning the tomom curricular experts pipeline. It uses the house's `.chtpm` text-based UI format (not HTML), rendered by the shared `khtpm_core_render.+x` process.

### Components

```
tomom_dashboard.chtpm       -- Layout: panels, buttons, cli_io inputs
  └── ${variable} placeholders  →  tomom_dashboard_data.txt
                                    └── Generated by tomom_dashboard.py
                                          ├── Reads curriculum_bank.txt
                                          ├── Reads curriculum/*/loss.txt
                                          ├── Reads debug_chain.txt
                                          └── Reads curriculum/<name>.txt (vocab)

pal/tomom_dashboard_module.pal        -- VM loop: refresh + key dispatch
pieces/apps/tomom_app/interact_relay.txt -- Key event history
button.sh                            -- Launcher (run/watch/handtune/compile)
```

### Dashboard Sections

1. **Stats Bar** — Subjects trained/N, avg/min/max loss, expert count, last response
2. **Curriculum List** — All 27 experts with loss values; click to select
3. **Routing Decisions** — Which experts were consulted for the latest generation
4. **Chat History** — User prompt, router decision, expert selection, model response
5. **Token Inspector** — Inspect/ edit vocab tokens (word, number, weight, embedding preview)
6. **Inputs** — Prompt, word edit, weight edit via `cli_io` elements

### Running

```bash
# Generate dashboard data (required before rendering)
python3 harnec/tomom_dashboard.py --refresh

# Live-updating mode
python3 harnec/tomom_dashboard.py --watch &

# Render via khtpm_core_render (requires full X11 stack)
../../_.monads/_.livedesk-taskbar/ops/+x/khtpm_core_render.+x . pieces/chtpm/layouts/tomom_dashboard.chtpm

# Via button.sh
./button.sh run     # one-time refresh
./button.sh watch   # live mode
```

### Hand-Tuning Cycle

```bash
# Full cycle: tune → bridge → validate → commit/revert
python3 harnec/run_handtune.py \
  --curriculum Mathematics \
  --prompt "Explain quadratic equations" \
  --behavior "Boost 'equations' weight" \
  --auto-commit
```

### Weight-Editing Policy

- **Safe to edit**: `weight` field (5th column in vocab .txt files)
- **Never edit**: `embedding`, `pe`, `bias1-4` fields (disrupts trained matrices)
- After editing: fine-tune 10 epochs from trained baseline, auto-revert if loss worsens
