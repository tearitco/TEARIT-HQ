--- BUG 1: [Map Loading...] FIX ---
Root cause: chtpm_parser.c load_vars() line 1187-1189 (SAME in both original and PAL)
  - load_state_file("pieces/apps/player_app/state.txt") loads game_map correctly at line 976
  - BUT later, the view_path check at line 1187 OVERRIDES game_map with
    "[Map Loading...]" when view_path is NULL (no view.txt found)
  - This happens AFTER state.txt is loaded, clobbering the real value
Fix applied: Added guard `if (strlen(get_var("game_map")) == 0)` before
  setting the default. Now state.txt value persists.
  - Applied to BOTH chtpm_parser.c and chtpm_parser_pal.c

--- BUG 2: [^] (cli_io starts active) ---
Root cause: orchestrator.c mkdir did NOT create pieces/apps/player_app/manager/
  - gui_state.txt clear failed silently (directory didn't exist)
  - Old gui_state.txt from previous runs persisted
  - cli_buffers.txt also persisted with old input
Fix applied: 
  - mkdir now creates manager/ subdirectory
  - Clear cli_buffers.txt and interact_relay.txt on startup

--- RENDERING PIPELINE (from x0.pet study) ---
1. chtpm_parser writes frame to pieces/display/current_frame.txt
2. chtpm_parser pulses pieces/display/renderer_pulse.txt (appends "P\n")
3. renderer.c monitors frame_changed.txt and renderer_pulse.txt
4. renderer reads current_frame.txt, displays to stdout with timestamp
5. renderer also appends to pieces/display/frame_history.txt (scrollback)

--- KEY FILES ---
- orchestrator.c: fork/exec launcher, clears all state, compiles binaries
- chtpm_parser_pal.c: PAL fork parser, layout rendering, keyboard processing
- game_manager.c: polls player_app/history.txt, calls word_turn_input
- keyboard_input.c: raw terminal, writes KEY_PRESSED to keyboard/history.txt
- renderer.c: reads current_frame.txt, writes to stdout + frame_history.txt
- word_compose_frame.c: writes game_map to state.txt
- word_turn_input.c: updates ledger, accepts word argument
- lpns_word_menu.chtpm: layout with module/interact/cli_io/button tags

--- DATA FLOW ---
keyboard_input -> keyboard/history.txt -> chtpm_parser_pal reads/processes
                                              |
                                    cli_io typing -> Enter -> gui_state.txt
                                              |              + inject KEY:13
                                              v
                              player_app/history.txt -> game_manager reads
                                              |
                                    word_turn_input -> word_compose_frame
                                              |              |
                                              v              v
                                    frame_changed.txt   state.txt
                                              |
                                    renderer -> stdout
