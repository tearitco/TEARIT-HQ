## The training flow (what points at what)
1. LINUX curls http://10.0.0.144:11434 (llama3 teacher) -> corpus text
   -> saved to ~/iqabod-store/<name>/corpus.txt on LINUX
2. LINUX runs ./+x/main_orchestrator.+x vocab_only + train
   -> weights land in ~/iqabod-store/<name>/curriculum/<name>/ on LINUX
3. LINUX evaluates -> small report row sent BACK to this box
   -> appended to curricula.pdl / training-report.txt here (tiny only)
Nothing heavy ever sits on THIS box.

## SSH command cheatsheet
  Linux:  sshpass -p root ssh jb@10.0.0.187
  Mac:    sshpass -p 1234 ssh lfs.master@10.0.0.144
  scp to Linux node store: sshpass -p root scp <file> jb@10.0.0.187:~/iqabod-store/

  (default 1e-5 never leaves the random floor - proven). conv-g1 has it.

  compiled binary on Linux node). Rebuild on node, not here.
