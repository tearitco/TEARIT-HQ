# Sonnet Handoff Template
Use this file when a task is genuinely too hard for Haiku.

## Instructions for Haiku (Me)
1. Before creating this file, TRY to break the task into smaller chunks
2. If you still think it's too hard, THEN create this file
3. Fill in the sections below (be specific, not vague)
4. Message the user with this file path and ASK: "This feels too hard for Haiku. Should I hand off to Sonnet, or should we break it into smaller pieces first?"
5. Don't just create this and assume the user will use it — suggest it explicitly
