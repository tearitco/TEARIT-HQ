The chain

Every pet, coin and message here is a row in one file that lives in your browser. Every block is re-checked here, with the same rules as our C tools. Nothing leaves your machine until you export it.

Import and fetch both go through the fork rule: both copies are verified and the one with the most work wins (a tie keeps yours).

Install the house on your computer

Linux, a terminal, a C compiler. This is the house's original install location:

curl -fsSL https://raw.githubusercontent.com/tearitco/tearit-install/main/install.sh | sh -s -- tearit-hq
It builds into ~/tearit-hq and writes a tearit-hq launcher to ~/.local/bin.

Submit without a server

Open an issue labelled tx on the repo with rows, one per line (TX|from|to|amount|ts|id, MSG|from|channel|text|ts, FAUCET|wallet|amount|ts, or a ranch row). The steward bot verifies each, mines a block and closes the issue. Machine-readable list: commands.json.
