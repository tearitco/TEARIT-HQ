# scrypts — the house's launch scripts

The house's launch scripts live here, one script per subfolder, plus a
main dispatcher (`scrypts.sh`) out in the house root (`44.xyz...00.11/`).

## Layout

```
44.xyz❤️‍🔥️00.11/                 <- house root (main dir)
  scrypts.sh                     <- main dispatcher (the entry point)
  $.crypts/                      <- autostart + scrypts
    button.sh                    <- legacy autostart control (still works)
    button.ps1                   <- Windows parity
    autostart.pdl                <- the startup list (what opens at login)
    scrypts/
      autostart/run.sh           <- autostart control (wrapper)
      openall/run.sh             <- always-open the current desk set
      book-stack/run.sh          <- open book-stack alone (wrapper)
    ops/                         <- crypt_autostart binary + source
```

## Main dispatcher: `scrypts.sh`

Run it from the house root:

```
./scrypts.sh openall            # open the current desk set, no questions
./scrypts.sh book run           # open book-stack alone (window + reader)
./scrypts.sh book window        # open just the book-stack window
./scrypts.sh read               # open book-stack's reader menu
./scrypts.sh autostart run      # run the autostart.pdl set (mount + launch)
./scrypts.sh autostart on       # enable auto-opening at login
./scrypts.sh autostart off      # disable auto-opening at login
./scrypts.sh autostart status   # is autostart on or off
./scrypts.sh list               # list scrypts + currently running windows
./scrypts.sh help               # this help
```

Every command is idempotent: re-running never duplicates windows that
are already open.

## What each scrypt does

### `openall/run.sh` — always-open the current desk set

Opens the current desk set on the desktop, unconditionally
(ignores the autostart enable/disable toggle):

- ava, asa (desktop entities)
- m1_ninjadragon, m8_redhorned (*.monads/*.muchi-pet entities)
- book-stack (the book entity window)
- the taskbar

It also mounts the shared asset drive (silently) so book-stack's bible
assets are available. Only launches what isn't already running.

### `autostart/run.sh` — the login autostart

Controls the list in `$.crypts/autostart.pdl`:

- `run` — quit the current livedesk, then mount + launch everything in
  the list (this is what `$.crypt` / the XDG autostart entry calls).
- `on` / `off` — toggle `STATE|enabled` in autostart.pdl.
- `status` — show the current enabled state.
- `compile`, `check`, `install-xdg` — build/verify tools.

To add an app to startup, add a `LAUNCH | <name> | '<command>'` row to
`$.crypts/autostart.pdl` (see the existing rows for the exact format).

`restore-last-open` is deliberately off in `$.crypts/autostart.pdl`, so
`$.crypts/button.sh run` now uses the curated launch list instead of the
last-open session snapshot.

### `book-stack/run.sh` — open book-stack alone

- `run` — open the book-stack window and start the reader menu.
- `window` — open just the window.
- `read` — start the reader menu (window must be open).
- `kill` — close the book-stack window.
- `check` — verify the binaries and paths.

It forwards to `*.monads/*.book-stack/button.sh` (and `run.ps1` on Windows).

## When is this run automatically?

If XDG autostart was installed once (`./scrypts.sh autostart install-xdg`),
the desktop launches `scrypts.sh`'s autostart at login. You can also run
any command by hand at any time — nothing here requires a login session.

## Windows

- `scrypts.sh` is the Linux entry point (bash).
- Windows uses `$.crypts/button.ps1` for autostart and
  `*.monads/*.book-stack/run.ps1` for opening book-stack.
