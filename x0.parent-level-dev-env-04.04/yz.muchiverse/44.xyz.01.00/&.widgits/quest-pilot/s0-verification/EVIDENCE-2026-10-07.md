Findings worth keeping: (a) the item glue script takes the package dir as `$2`, so calling it without arguments exits silently (my first test of it did exactly that); (b) `poll_agent_history()` discards the content of a relay file the first time it sees one (`g_history_cursor` starts at -1), but the renderer creates the file at startup, so that was not the cause here; (c) the relay path is `KEY_PRESSED` -> `dispatch_relay_code` -> `handle_key`, mouse press -> `popup_handle_click` (a dock/popup-oriented handler), so a relayed click may not reach HQ item rows at all: worth a control test against a minimal window the Tester launches itself; (d) the relay masking/non-masking of real focus bugs remains unproven in both directions.
