Write ONE self-contained C source file, program name var_cmp. Reply with ONLY the C code inside a single ```c fenced block, no explanation.
Usage: var_cmp <state_dir> <a> <op> <b> <out>   (exactly 5 arguments). It compares two numbers and stores 1 (true) or 0 (false) in a variable file.
- state_dir must be an existing directory. It may hold variables.txt: lines of the form name=integer (a missing file or missing name reads as 0; a line matches a name only when the text before the first '=' equals the name EXACTLY, so name x must not match a line xx=5; a value that is not a whole base-10 integer reads as 0; strip a trailing newline or carriage return).
- <a> and <b> are each either (1) a whole base-10 signed integer, optional leading + or - and at least one digit, nothing else, fitting in long long (use strtoll with errno and end-pointer checks; reject hex, floats, empty text, trailing characters, overflow), or (2) a variable name matching [A-Za-z_][A-Za-z0-9_]* whose value is read from variables.txt as above. Anything else is a bad operand.
- <op> is one of the symbols == != < <= > >= or the words eq ne lt le gt ge (same meaning, in that order). Anything else is a bad operator.
- <out> is a variable name matching [A-Za-z_][A-Za-z0-9_]*, else bad out name.
- On success: write out=1 or out=0 into state_dir/variables.txt: replace the FIRST line whose name is exactly <out> in place (all other lines unchanged and in the same order, later duplicates untouched); if there is no such line append "out=<0|1>\n" at the end; make sure every line of the rewritten file ends with a newline (the original may lack one on its last line); create the file if missing. Write through a temporary file state_dir/variables.txt.tmp and rename() it over variables.txt. Print "1\n" or "0\n" on stdout and exit 0 (false is NOT an error).
- On any error (wrong argument count, bad operator, bad operand, bad out name): exit with status 2, leave variables.txt untouched, print a short message on stderr, and when state_dir is an existing directory append one line "ERR|var_cmp|<reason>|<offending text>\n" to state_dir/op_errors.txt where <reason> is bad-operator, bad-operand or bad-out-name (use "usage" for a wrong argument count). If state_dir is not an existing directory just print the message and exit 2 without creating anything.
Must compile with no warnings: gcc -std=gnu11 -Wall -Wextra -Werror -O2. Use only the C standard library plus <sys/stat.h> (for stat) . Do not use system() or popen().
