# concept-bank/common_events/entity_grade_tick
The Grade Tick: a common event (same package shape as `&.widgits/eden/common_events/eden_day_tick`). Install = copy `event_pkg/` to `<house>/common_events/entity_grade_tick/`, copy `^.hai-horn/curriculum.pdl` and `skillbook.pdl` into `<house>/game/school/`, put the compiled `entity_grade.+x` at `ops/+x/` beside it, and add a schedule row `common:entity_grade_tick` with `repeat=every:1day` (as the Eden README does for the day tick). Its page runs `entity_grade tick . ../participants`: every entity folder under `game/participants/` gets its MP refilled, its report card refreshed (`variables.txt`: grade_*), and an automatic graduation where the curriculum allows it (`approval=auto`); grades with `approval=person` wait for `graduate <name>`.
**Not yet run through the real clock** (the harness exercises `entity_grade tick` directly; the lc_clock wiring is untested here).
