TITLE | Plugs and harnz | Day and night is the first plug. Built and tested 2026-11-14 | This is a short progress video. We split the editor's tools into events, plugs, page tools and tests, and we turned the day and night cycle into the first plug.
SLIDE | Four words | Event: a built in engine command, like teleport or a door ; Plug: an optional behavior with parameters and an on or off switch ; Harnz: a one shot tool for the open page ; Test: a harness case for agents | An event is something the engine already has. A plug is optional, has parameters, and can be switched on or off. A harnz is a one shot tool for the page you have open. And a test is a harness case, mostly for agents.
SLIDE | The judge | If RPG Maker has an event for it, it is an event ; If any engine should have it, it is an event ; Otherwise it is a plug ; When unsure, make it a plug | Here is the rule for sorting them. If RPG Maker has an event for it, or any engine should have it, it is an event. Otherwise it is a plug. Day and night is a plug, because a game does not have to have a night.
SLIDE | The plug is one visible file | ENABLED switch, on or off ; PHASE rows: the hour, the tint, the sky ; PARAM rows: typed values the event pages read ; Defaults equal the old hard coded values | The whole cycle now lives in one visible file. It has the switch, the hour each phase starts, the tint and the sky, and typed parameters. The defaults match what used to be hard coded, and a test proves that for all twenty four hours.
SLIDE | Event pages read the plug | A page names a value: tint equals plug day night tint dusk ; The value is read when the command runs ; Plug off, missing, or out of range: the command is refused ; Never run with a stale value | The event pages no longer hold the numbers. A page just names a plug parameter, and the engine reads it when the command runs. If the plug is off, or the value is wrong, the command is refused instead of running with a stale value.
SLIDE | Proof | day night plug: 35 checks passed ; plug reference: 60 checks passed ; tools menu: 45 checks passed ; harness menu: 60 checks passed ; Every case has negative controls, and a mutation was caught | Here is the proof. Four cases, all passing, with negative controls. When I broke the code on purpose, the tests failed, so the checks can really fail.
SLIDE | Not built yet | A generic plug header and a loader for many plugs ; The harnz kind that fires an event, and triggers ; The maker inside the editor ; The LyfeDesk cell shows only the global rows ; Live versus restart toggling for plugs that change outcomes | Here is what is not built yet. A general plug header, a loader for many plugs, the harnz kind that fires an event, triggers, and the maker inside the editor. The top taskbar cell shows only the global rows for now.
