FOOTER | proposed plan
TITLE | Phase three: weights as plain text files | The first pets-learn loop, about one week | Phase three gives pets a learnable behaviour that is stored as plain text you can edit.
SLIDE | Why now | The decision ledger already records one row per actor choice; The harness can grade outcomes with code, not opinion; Pets cannot yet improve from what happened | We already record one row for every choice an actor makes, and the harness can grade outcomes with code. What is missing is the step where a pet actually improves.
SLIDE | What we build | A bank file of weight rows: key, weight, source, grade, date; The pet reads the bank when it chooses; A daily review verb promotes or demotes rows by their graded outcomes; Start with one game and one behaviour | We build a bank of weight rows, each with a key, a weight, where it came from, its grade and a date. The pet reads the bank when it chooses. A daily review promotes or demotes rows by their graded results. We start with one game and one behaviour.
SLIDE | How we prove it | Scripted episodes where one choice clearly wins; After the review the winning row's weight rises, shown in the file; You edit a row by hand and the next choice changes | We prove it with scripted episodes where one choice clearly wins. After the daily review, that row's weight must rise in the file. Then you edit a row by hand, and the pet's next choice must change.
SLIDE | Risks | A single shared bank can make every pet behave the same; Grading must be done by code, otherwise the loop learns from noise; Free model quotas must not be burned by the loop | The risks are monoculture, if every pet shares one bank, and noisy grading, which is why grading is done by code. The loop also must not burn the free model quota.
SLIDE | Done means | One behaviour demonstrably improves from graded results; Every weight is a readable, editable file row with its source; The same loop is ready for other games | Phase three is done when one behaviour measurably improves from graded results, every weight is a readable file row, and the loop is ready to reuse in other games.
