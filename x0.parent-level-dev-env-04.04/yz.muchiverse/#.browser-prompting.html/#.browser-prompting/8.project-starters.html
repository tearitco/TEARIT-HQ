🏦🌾 Business sim game (banks/stores/farmers/scientists)

Banks + stores on a board trading stocks/bonds, players work for salary or trade goods with farmers/miners/scientists doing R&D.

Segregation via `3.file`

The taskbar's real HQ header cell 3 is "file" (new/save/save-as/load). Each save-slot under the file cell IS your project boundary — the game lives entirely inside its own file/session. Default to keeping it local; only promote a genuinely reusable capability (e.g. a generic stock-ticker widget) out to shared code deliberately.

  pass."

Build order: (1) one static desk + one bank pal with a real price-list state file, (2) one player pal that can buy/sell against it, (3) THEN add farmers/salary/R&D.
